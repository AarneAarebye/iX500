# Photos from the CanoScan 8800F: the scanix500 side Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The CanoScan 8800F scans a photo to JPEG or PNG at up to 1200 dpi, over a chosen scan area (A4, A5, A6, 10 x 15 cm, 13 x 18 cm), through `POST /scan` on the Mac bridge and on `scanix500-server`; PDF stays the default and the iX500 is untouched.

**Architecture:** `scanners.py` gains the area table, the 100-megapixel size limit and the 8800F's new capabilities (`formats`, `areas`, 1200 dpi). `protocol_v2.validate` checks the new request fields; the chosen `format` and `area` travel `POST /scan` -> `Profile` -> CLI `--format`/`--area`; `PySaneFlatbed` scans only the area; a new `images.py` writes the JPEG or PNG. The fake backend serves an optional `fake:photo` scanner for the conformance suite. The spec is `docs/superpowers/specs/2026-10-24-photos-protocol-and-8800f-design.md`; the protocol text itself is written by the sibling plan in dossiary-scan-helper (`docs/superpowers/plans/2026-10-24-photos-protocol.md`), which does not have to be done first: nothing here imports it.

**Tech Stack:** Python 3.11+, Pillow (already a dependency), python-sane (SANE `pixma` backend), pytest.

## Global Constraints

- **Additive protocol, version stays 2:** a scanner entry without `formats` offers only `["pdf"]`; a request without `format` is a PDF; `format`/`area` that a scanner doesn't offer are **422** (wrong JSON types are **400**, checked first, as PROTOCOL.md's validation order requires); old clients and the iX500 behave exactly as before.
- **Request refusals (422), each with its own plain message:** `format` not in the scanner's `formats`; `area` not in the scanner's `areas`, or `area` for a scanner without `areas`; `ocr: true` with an image format; `colorMode: "bw"` with `format: "jpeg"` (JPEG can't be 1-bit; PNG and PDF can); an area and resolution whose pixel count is **over 100,000,000** (the limit is inclusive: exactly 100,000,000 is allowed).
- **Areas** (id: width x height in mm, upright, anchored at the glass's corner mark): `a4` 210 x 297, `a5` 148 x 210, `a6` 105 x 148, `10x15` 100 x 150, `13x18` 130 x 180. Pixel count = `round(width_mm / 25.4 * dpi) * round(height_mm / 25.4 * dpi)`.
- **The 8800F's entry:** `formats: ["pdf","jpeg","png"]`, `areas: ["a4","a5","a6","10x15","13x18"]`, `resolutions: [150,300,600,1200]`; the iX500's entry has no `formats` and no `areas` and is unchanged.
- **Response:** an image file has `pages: 1`, a name ending in `.jpg` (JPEG) or `.png`, base64 `data`, no `ocrJob`; the message is `"1 image scanned."`; PDFs keep `"N pages scanned."`.
- **Flatbed pages are pass-through** (no trim, snap or blank filter), as in 0.8.0; image encoding: JPEG quality 92, PNG 1-bit for black & white, the dpi embedded in both.
- **Error text sent to Dossiary stays English; no new `t()` strings.** The Mac app's own menu, its Hardware Button profile and its buttons are unchanged (PDF, A4).
- `scanix500.server` must not import rumps/AppKit (`tests/server/test_runtime.py` checks it). Hardware code (`PySaneFlatbed`'s SANE calls) is verified manually, not mocked.
- Run tests with `.venv/bin/python -m pytest` from the repo root. Baseline before this plan: **412 passed**.
- Work on a feature branch off `main` (after the spec branch `spec/photos` is merged or cherry-picked); never commit to `main` directly. End commit messages with the attribution lines from the session's system reminder.

```python
"""Writing a scanned page as a JPEG or PNG file."""

from pathlib import Path

from PIL import Image

JPEG_QUALITY = 92
EXTENSIONS = {"jpeg": "jpg", "png": "png"}


def save_image(image: Image.Image, path: Path, fmt: str, dpi: int) -> None:
    """Writes `image` to `path` as "jpeg" or "png", with the dpi embedded. A
    1-bit page (black & white) stays 1-bit as PNG; JPEG can't be 1-bit, so it
    becomes 8-bit gray there."""
    if fmt == "jpeg":
        if image.mode not in ("L", "RGB"):
            image = image.convert("L" if image.mode == "1" else "RGB")
        image.save(path, "JPEG", quality=JPEG_QUALITY, dpi=(dpi, dpi))
    elif fmt == "png":
        image.save(path, "PNG", dpi=(dpi, dpi))
    else:
        raise ValueError(f"unknown image format: {fmt!r}")
```

Replace `compute_output_paths` in `src/scanix500/router.py` with:

```python
def compute_output_paths(
    destination: Path, count: int, *, now: datetime | None = None, extension: str = "pdf"
) -> list[Path]:
    timestamp = (now or datetime.now()).strftime("%Y-%m-%d_%H%M%S")
    if count == 1:
        return [destination / f"scan_{timestamp}.{extension}"]
    return [destination / f"scan_{timestamp}_{i + 1}.{extension}" for i in range(count)]
```
